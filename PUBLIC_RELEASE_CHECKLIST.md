# Public release checklist

## Prepared locally

- Release version: `v1.0.0`
- Reproducibility archive: `TISTA_Blood_Advances_reproducibility_v1.0.0.zip`
- Analysis scripts, fixed signatures, subject-level results, 100 benchmark replicates, null-label results, figures, and source-data tables are included.
- `CITATION.cff`, `LICENSE`, `requirements.txt`, and checksums are included.

## Actions requiring an author account

1. Create a public GitHub repository and upload the contents of `reproducibility_v1.0.0`.
2. Create Git tag and release `v1.0.0`.
3. Connect the repository to Zenodo, archive release `v1.0.0`, and mint the DOI.
4. Replace `[PUBLIC REPOSITORY URL; VERSIONED RELEASE REQUIRED BEFORE SUBMISSION]` in the manuscript with the repository URL, version, and DOI.
5. Replace the provisional repository sentence in the cover letter with the permanent URL and DOI.

## Author confirmations before submission

- Confirm that all authors approved the final submitted version.
- Confirm Jun Peng's preferred degree/credential if the journal submission system requires one; the letter currently uses the safe name-only form.
- Verify the exact modified IWG response threshold from the original study Supplementary Appendix. Until verified, retain the conservative wording that response grouping follows the source study.
