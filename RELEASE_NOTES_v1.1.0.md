This release adds the primary-cohort deepening analyses requested during final manuscript audit:

- exclusion sensitivity for responders R7, R10, and R11 with recent IVIG exposure;
- a selection-independent 11,863-gene analysis;
- gene-wise variance-standardized genome-wide partial R2;
- alternative within-sample rank-based platelet scoring with five nonplatelet lineage controls;
- Supplementary Figure 6 and complete source-data tables;
- exact software versions for the added analyses;
- revised manuscript, supplement, and cover letter wording that distinguishes the selected treatment-responsive gene set from the complete expressed-gene universe.
